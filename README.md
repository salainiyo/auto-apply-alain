# Job Freshness & Application Tracker

A full-stack application designed to track job applications and monitor the freshness of job postings to ensure applications are sent to active roles.

## Tech Stack
- **Backend:** Python / FastAPI
- **Frontend:** JavaScript
- **Infrastructure:** Docker

## Project Focus
This is an active utility project. The core focus is currently on tracking job posting freshness and managing application states, ensuring high reliability in job hunting workflows.
